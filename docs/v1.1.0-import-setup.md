# v1.1.0 — import and configuration

This is an Automation Anywhere 360 Community Edition **interactive educational bot**. The packaged ZIP is a sanitised copy of the locally tested workflow. Its ZIP integrity and bot JSON structure were checked; a fresh Control Room import and runtime test of that exact sanitised package have **not** been performed.

1. Import the native `NHL_Hockey_Data_Collector_v1.1.0_AA360.zip` without overwriting an existing working bot. Unpacked source files are for inspection, not direct import.
2. Copy `config.example.json` to `config.json` on your own computer. Edit the `output.directory` value to a writable directory, create that folder, and use double backslashes in JSON Windows paths.
3. In the imported bot, set the File-type `fConfigFile` variable to the actual location of `config.json`. The packaged `C:\\Automation\\NHL_Hockey_Data_Collector\\config.json` is only a generic example. The bot does **not** locate its config automatically.
4. Confirm required Chrome/browser automation and Bot Agent prerequisites. Start with a fresh browser session at the initial hockey forms page. Avoid interacting with the browser while running.
5. For a controlled check, set `max_page_attempts` to `3`, run manually and inspect the configuration message and 50-row consolidated CSV. Restore `30` for the full dataset, subject to the source site's rules.

The `source.next_link_xpath` JSON field is **not wired into** the recorded Next-link selector. Startup validation is basic: missing files/nodes, malformed JSON, non-numeric values and inaccessible folders are not comprehensively handled. There are still interactive Message boxes and no structured error log/retry policy. The pre-navigation delay is not an HTTP-rate measurement. Check [Scrape This Site FAQ](https://www.scrapethissite.com/pages/faq/) and [robots.txt](https://www.scrapethissite.com/robots.txt) before repeated or unattended use. No full compliance claim is made.
