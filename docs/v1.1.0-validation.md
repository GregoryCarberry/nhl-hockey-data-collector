# v1.1.0 — test evidence and limitations

## Verified original development bot (6 November 2026)

- External JSON controls URL, page-attempt cap, delay and output paths. Empty/whitespace-only filenames and output directories were individually tested to trigger an error message and Stop; invalid numeric bounds were also tested.
- Trailing directory backslash was tested. An initial run showed doubled separators because the CSV path Assign actions ran before normalisation. Moving the three Assign actions after normalisation fixed the constructed paths.
- The string replacement regex for trailing backslashes required entering a doubled dollar sign in the AA360 editor to represent the regex end anchor. The editor initially rejected the single dollar sign; the correction cleared validation and the corrected path was observed at runtime.
- A full local run with `max_page_attempts=30` initially produced 532 records and reported 22 attempts / 22 unique pages / no Next. The CSV began with Los Angeles Kings 1992, indicating the first 50 expected records were absent. An old browser window was suspected, **not proven** as the cause.
- A second full run, without workflow modifications, produced a fresh consolidated CSV modified 6 November 2026 02:32:06 UTC: **582 data rows**, one nine-column header, no fully blank rows and no identical duplicate rows. Records 1–25 and 26–50 matched independently saved page-1/page-2 reference CSVs. Last-page diagnostic matched the final seven consolidated records, ending Winnipeg Jets 2011.

## Scope of the result

The full successful regression applies to the **original local bot**, not a separately imported copy of the sanitised release ZIP. The current dataset is a third-party educational website and may change. A successful scrape is not proof of all site rules being met; navigation pacing was not measured at HTTP request level. The bot remains interactive and does not classify apparently successful partial output reliably.

## Next version candidates

Check browser start state and initial page identity; report partial/incomplete runs; introduce scoped error handling, logging and non-interactive status. These are not v1.1.0 features.
